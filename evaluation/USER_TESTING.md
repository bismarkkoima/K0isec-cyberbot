# User testing kit

Use this kit to run the usability study described in section 7 of the capstone report.

## Before the session

- Get informed consent (see the consent statement below). Do not record names in the results.
- Set up the app on a laptop with Ollama and the default model, and open http://127.0.0.1:5000.
- Print this sheet and the SUS questionnaire.

**Consent statement (read aloud):** "This study tests a computer program, not you. There are no wrong
answers. You can stop at any time. We won't record your name, and nothing you type is sent anywhere."

## Tasks

Time each task and note whether it was completed without help (✔), with a hint (½) or not completed (✘).

| # | Task |
|---|---|
| T1 | Make the text bigger. |
| T2 | Ask the assistant: "What should I do if someone calls asking for my bank PIN?" |
| T3 | Check sample message A (scam): *"Royal Mail: your parcel could not be delivered. Pay the £1.99 redelivery fee here: https://royalmail-redeliver.info/pay"* |

## System Usability Scale (SUS)

Participants rate each statement from 1 (strongly disagree) to 5 (strongly agree).

1. I think that I would like to use this system frequently.
2. I found the system unnecessarily complex.
3. I thought the system was easy to use.
4. I think that I would need the support of a technical person to be able to use this system.
5. I found the various functions in this system were well integrated.
6. I thought there was too much inconsistency in this system.
7. I would imagine that most people would learn to use this system very quickly.
8. I found the system very cumbersome to use.
9. I felt very confident using the system.
10. I needed to learn a lot of things before I could get going with this system.

**Scoring:** for odd items subtract 1 from the answer; for even items subtract the answer from 5.
Add the ten results and multiply by 2.5 to get a score from 0 to 100. Scores above about 68 are
generally considered above average.

## Follow-up questions

- What did you like most?
- What was confusing or hard to read?
- Would you use this at home? Would you recommend it to a friend?
